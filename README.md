# sunxue · 孙学访谈知识库

把《对话孙宇晨：年轻人如何抓住 AI 时代的机会？》的主要内容整理成可供 AI 按需读取的内容型 Skill，并附上 **77 页详细解读 PDF**。

**4 小时 22 分钟原片 · 16 张主题知识卡 · 20 个完整章节 · 原片时间索引**

[下载 Skill 安装包](downloads/sunxue-skill.zip) · [阅读详细版 PDF](docs/sunxue-detailed.pdf) · [浏览主题知识卡](references/knowledge-map.md) · [原片与章节索引](references/source-index.md)

## 这份 Skill 能做什么

- 解释这场访谈中的概念、主要主张、具体例子与上下文。
- 比较前后观点，例如“先探图”与“先上路”、“高度信任 AI”与“保留个人判断”。
- 按问题查找原片讨论范围和详细章节，区分访谈内容与整理者的分析。
- 在你要求时，将相关观点用于理解自己的学习、项目或创作选择，并说明适用条件。

它以内容知识为主体。20 章文字与 PDF 主体同源，主题卡只负责快速导航；需要详细解释时，Skill 会进一步读取对应正文。

## 开始使用

**直接阅读**：无需安装，打开 [主题知识卡](references/knowledge-map.md) 或 [详细 PDF](docs/sunxue-detailed.pdf)。PDF 含可点击目录、162 个书签和原片时间链接。

**作为 Skill 使用**：下载 [sunxue-skill.zip](downloads/sunxue-skill.zip)，解压后保留完整的 `sunxue/` 文件夹及其层级。入口是 `sunxue/SKILL.md`；不要只复制这个入口文件，否则会缺失正文。

在支持本地 Skill 的 Codex 环境中，可把该文件夹放到用户级 `~/.agents/skills/`，或项目级 `.agents/skills/`。也可以让已安装的 Skill Installer 从本仓库安装。具体发现位置和界面随宿主而定，参见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

在 Codex 中用 `$sunxue` 指定调用。例如：

```text
请用 $sunxue 梳理这场访谈最重要的观点，区分访谈内容和编辑归纳。
```

```text
请用 $sunxue 解释“先探图”和“先上路”是否矛盾，给出原片时间和上下文。
```

```text
请用 $sunxue 解释“五千万美元去上班”背后的意思，不要只讲金额。
```

```text
请用 $sunxue 帮我理解这套观点对我的AI学习项目有什么启发。
我每周可用5小时，预算有限。请区分访谈观点、适用条件和你的应用建议。
```

此包仅含内容和说明，不需要 API Key、外部连接器或运行脚本。回看原片、核验当前事实时才需要相应网络访问。
